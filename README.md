# bepin.github.io
A repository to maintain and share data and outputs related to the BE-PIN project (https://www.pandemicintelligence.be/the-project).
index.html defines an interactive network visualization of the mapping between information needs, data needs, and datasets as defined in data/mapping_structure.json (output of work package 1). It is deployed in https://be-pin.github.io/ (depends on /lib folder).
